## Команды

```
npm install
npm run dev       # локальный сервер
npm run build     # сборка в dist/
npm run thumbs    # превью для галереи
```

Сайт лежит в `frontend/`, поэтому vite запускается с указанием этой папки.

### Превью галереи

В сетке галереи показываются уменьшенные копии из `frontend/public/images/thumbs`,
оригинал грузится только при открытии фото. После добавления новых снимков
в `gallery-data.js` нужно выполнить `npm run thumbs` — команда сделает
недостающие превью, обновит устаревшие и уберёт лишние.
`npm run thumbs -- --force` пересобирает все заново.
